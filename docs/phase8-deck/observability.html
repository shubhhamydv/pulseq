06 / OPERABILITY
Operators get a live view of system health
Signals answer four questions: what is happening, where is capacity, what failed, and which process is alive?
VISUAL CONTROL PLANE

React operations dashboard

Jobs, failed work, DLQ, workers, metrics, and job detail are connected to live backend state.

SCRAPEABLE TELEMETRY

Prometheus-compatible metrics

Counters, gauges, and execution-latency histograms expose queue depth, outcomes, retries, and health.

PROCESS LIVENESS

Worker heartbeats

Redis-backed registration and refresh classify workers as healthy, degraded, or offline.

CORRELATED EVENTS

Structured Pino logging

Request IDs, job IDs, worker IDs, attempt numbers, status, and duration aid incident tracing.
